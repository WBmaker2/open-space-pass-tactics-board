# 콘텐츠 검수 문서 (교사·교과 검수자용)

> 상태: **검수 대기(pending)**. 아래 항목은 체육 교사 또는 교과 검수자가 사람 검수로 승인해야 한다.
> 자동화 테스트 통과는 교과 검수 승인을 의미하지 않는다.

## 검수 대상

1. 6개 고정 미션의 장면 구성과 정답 데이터(`src/content/missions.ts`)
2. 어린이용 문구(지시문, 피드백, 근거 선택지, 결과 기록 문장)
3. 격자 모형이 초등 수업에서 만들 수 있는 오해 가능성

## 모형의 한계(피드백·문서에 명시됨)

- 격자 전술판은 실제 경기의 속도·신체·판단 전체를 대표하지 않는다.
- lane의 열림·막힘은 검수된 데이터로만 판정하며, 좌표에서 물리적 시야를 추론하지 않는다.
- 이 앱은 운동 능력, 전술 지능, 승리 가능성을 평가하지 않는다.

- [ ] 승인 전에는 앱을 수업 자료로 배포하지 않는다.
