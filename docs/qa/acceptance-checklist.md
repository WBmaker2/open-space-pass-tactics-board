# 수용 기준 체크리스트 (QA)

> 각 항목은 `npm run verify` 결과와 사람 확인으로 채운다.

## 자동 검증

- [ ] `npm run lint` 오류 0건
- [ ] `npm run typecheck` 오류 0건
- [ ] 단위·컴포넌트 테스트 실패 0건 (6개 미션 + 네트워크·저장소 금지 경계 포함)
- [ ] 자동 접근성 검사 serious/critical 0건
- [ ] TS·TSX·CSS 500줄 이상 파일 0개
- [ ] `dist/index.html`과 해시 자산 생성, base `/open-space-pass-tactics-board/`
- [ ] E2E 시나리오 전부 통과
- [ ] `git diff --check` 출력 없음

## 앱별 완료 기준

- [ ] 실제 학생 이름·팀·경기 영상·위치 정보 입력란이 없다
- [ ] 복수로 열린 패스 길을 모두 유효로 인정한다
- [ ] 판정은 검수된 lane 데이터만 사용한다
- [ ] 드래그 없이 선수 이동과 패스 선택을 완료할 수 있다
- [ ] 결과가 운동 능력·전술 지능·승리 가능성을 평가한다고 표현하지 않는다

## 사람 검수 (자동화로 대체 불가)

- [ ] 체육 교사가 미션 데이터와 문구를 승인했다 (`docs/content-review.md`)
- [ ] 생성 이미지의 맥락·편향·권리를 확인했다 (`docs/image-rights-ledger.md`)
- [ ] 실제 태블릿(320px~1280px) 가독성을 확인했다
- [ ] VoiceOver 수동 검증은 계획상 범위에서 제외되었음을 확인했다 (실행·보고하지 않음)
