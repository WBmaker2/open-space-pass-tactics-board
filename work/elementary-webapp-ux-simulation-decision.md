# 시뮬레이션 필요성 결정

- 결정일: 2026-08-31
- 결정: `not-needed`

이 앱의 핵심은 변수를 자유롭게 바꾸는 시뮬레이션보다, 고정된 여섯 장면에서 공·수비·빈 패스 길·지원 위치를 관찰하고 근거를 말하는 것이다. 현재 SVG 경기판은 실제 선수 위치와 막힌 길을 정확하게 보여 주고, DOM 선택지·피드백·보고서가 관찰→예측→이동/패스→수비 변화→지원→기록 흐름을 충분히 드러낸다.

따라서 Canvas/WebGL/게임 엔진을 추가하지 않는다. 대신 현재 인터랙션의 다음 행동 발견성, 근거 보존, 어린이용 문장과 완료 회고를 개선한다. 정적 DOM/SVG로 설명할 수 없는 새로운 학습 목표가 생길 때에만 별도 시뮬레이션 검토를 연다.
