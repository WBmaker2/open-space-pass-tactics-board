# 어린 학습자 문장 감사

- 감사일: 2026-08-31
- 대상: 초등 3~6학년 체육 전술 활동
- 기준: 역할·방향·공간 관계를 먼저 읽고, 내부 식별자는 학습 문장의 주어가 되지 않게 한다.
- 원칙: 핵심 조건과 인과 관계는 줄이지 않고, 표현만 자연스럽게 다듬는다.

## 확정 변경 항목

| 위치 | 기준선 | 개선 문장/방향 | 이유 | 상태 |
| --- | --- | --- | --- | --- |
| 관찰 오답 | `${선수}은(는) ...` | `방금 고른 선수는 공을 가지고 있지 않아요.` | 조사 선택지를 어린이에게 떠넘기지 않음 | 완료 |
| 이동 선택지 | `A2 → c5r1 (오른쪽 한 칸)` | `오른쪽 위에 있는 선수를 오른쪽 한 칸으로 옮겨요.` | 역할과 방향을 먼저 제시 | 완료 |
| 지원 선택지 | `A1 → c2r2 (...)` | `패스를 보낸 선수를 오른쪽 위 한 칸으로 옮겨요.` | 지원의 목적과 움직임을 연결 | 완료 |
| 수비 공개 힌트 | `수비 D1이 c4r2 칸으로...` | `수비가 한 칸 움직였어요.` | 정답 판정용 ID를 학습 문장과 분리 | 완료 |
| 순서 피드백 | `검수된 계획(seq-left)` | `이동 → 패스 → 지원 순서가 이어졌어요.` | 내부 시나리오 ID 제거 | 완료 |
| 결과 카드 | `기록한 근거 문장이 없어요.` (지원 근거 선택 후) | 선택한 단계의 실제 근거 라벨 | 학습자의 선택을 정확하게 반영 | 완료 |

## 보존 항목

- `A1`, `A2`, `A3`, `D1`, `c열r행`, lane/state ID는 reducer, evaluator, 테스트의 판정 계약에서 보존한다.
- 보드의 사실 정보와 정답·오답 조건은 바꾸지 않는다.
- VoiceOver, TTS, 내레이션, 녹음은 이 감사 범위에 포함하지 않는다.

## 검증 방법

구현 후 관찰 오답 1회, 예측 오답 1회, 이동·지원 근거 선택 1회, 전체 완료 1회를 다시 실행한다. 문장 단독 확인과 실제 상태 전이 후 보고서 표시를 각각 확인하며, 교사·교육과정 적합성은 별도 사람 검토로 남긴다.

## 실행 결과

375px 브라우저에서 관찰 오답과 예측 오답 뒤 다음 행동이 보였고, 320/375px E2E에서 가로 넘침과 reduced-motion 회귀가 없었다. 전체 여섯 미션을 다시 실행해 미션 3·5·6의 이동/지원 근거 라벨, 자연어 보고서, takeaway를 확인했다. 교사·교육과정 적합성은 콘텐츠의 `reviewStatus: pending` 경계에 따라 사람 검토 대기다.
