# 빈 공간 패스 전술판 · 디자인 시스템

> 이 파일을 프로젝트의 화면 설계 기준으로 사용합니다. 생성된 검색 결과는
> `design-system/open-space-pass-tactics-board/MASTER.md`에 보관하고, 이 파일에서
> 제품 사실과 교육 맥락에 맞게 조정한 규칙을 우선합니다.

## 제품의 시각적 약속

이 앱은 게임 점수판이 아니라, 초등 학습자가 경기판의 빈 공간을 읽고 자신의
근거를 남기는 작은 작전 데스크입니다. 화면은 `작전판 → 지금 할 일 → 선택 근거 →
다음 행동` 순서로 읽혀야 합니다. 장식보다 판의 상태와 학습자의 판단을 먼저
보여 줍니다.

시각 언어는 체육관의 따뜻한 나무 바닥과 코치의 작전 노트에서 가져옵니다.
큰 전술판, 잉크색 제목, 민트색 열린 길, 주황색 수비, 산호색 필수 행동을
사용하되, 실제 경기 규칙이나 데이터처럼 보이는 장식은 추가하지 않습니다.

## 색상 토큰

라이트 모드만 제공합니다. 모든 색상 조합은 본문 4.5:1 이상을 확인하고, 색상만
으로 상태를 전달하지 않도록 텍스트와 선 스타일을 함께 사용합니다.

| 역할 | 값 | 사용처 |
| --- | --- | --- |

| 표면 | `#FFFDF8` | 작업 영역, 보고서 영역 |
| 잉크 | `#17332F` | 본문, 제목, SVG 주요 선 |
| 보조 잉크 | `#4B625C` | 설명, 범례, 보조 안내 |

## 글자와 간격

- 본문은 `16px`, 줄 간격은 `1.6`을 기본으로 합니다.
- 제목은 `Avenir Next`, `Apple SD Gothic Neo`, `Noto Sans KR`, `sans-serif` 순서로
  사용해 둥근 인상을 내되, 외부 글꼴을 불러오지 않습니다.
- 본문 읽기 폭은 `65~75ch`를 넘기지 않습니다. 작업 패널의 질문은 짧은 문장으로
  제한하고, 설명은 한 문단에 한 가지 메시지만 담습니다.
- 간격은 4px 단위(`4, 8, 12, 16, 24, 32, 48`)를 사용합니다.
- 모서리는 일반 표면 `16px`, 작은 입력 묶음 `12px`로 통일합니다. 모든 것을
  둥근 알약으로 만들지 않고, 단계 상태처럼 반복되는 짧은 요소에만 pill을 씁니다.

## 화면 구성

### 입구

제목과 목표를 먼저 보여 주고, 기존 체육관 일러스트는 장식으로 유지합니다.
미션 6개는 동일한 카드 그리드가 아니라 번호가 필요한 학습 순서 목록으로
표현합니다. 대상·시간은 한 줄 메타로 묶고, 저장하지 않음/평가하지 않음은
작은 안내 영역으로 분리합니다. `학습 시작하기`가 유일한 주 행동입니다.

### 작전 데스크

데스크톱에서는 왼쪽 전술판을 더 넓게, 오른쪽 현재 할 일을 짧고 단단한 열로
배치합니다. 오른쪽 열의 빈 공간을 카드가 억지로 채우지 않도록 내용 높이에
맞춥니다. 모바일에서는 전술판, 범례, 현재 할 일 순서로 쌓고 가로 스크롤을
만들지 않습니다.

전술판의 실제 SVG 기하와 선수/칸 이름은 학습 데이터이므로 바꾸지 않습니다.
SVG 밖의 테두리와 캡션만 작전 노트처럼 다듬습니다.

### 전술 기록

점수·순위·성공률을 만들지 않습니다. 여섯 미션의 처음 생각, 사용한 근거,
수정 결과를 읽기 쉬운 기록으로 보여 줍니다. 시작 판/마친 판은 학습 근거를
확인하는 시각 자료이므로 계속 노출하며, 인쇄 행동은 마지막에 배치합니다.

## 상호작용과 상태

- 모든 버튼과 선택지는 최소 `44px` 높이/너비를 확보합니다.
- `:focus-visible`은 3px 포커스 링과 2px 간격으로 항상 보입니다.
- 중요한 다음 행동은 두 곳만 `gi-pulse`를 사용합니다: `패스 길 확인`,
  `다음 지원 시험`. 모션 축소 시 애니메이션 대신 필수 외곽선을 표시합니다.
- 버튼 hover는 색상과 그림자만 바꾸며 레이아웃을 이동시키지 않습니다.
- 비활성 다음 버튼은 선택이 필요한 이유를 주변 질문으로 이미 설명하고,
  낮은 대비로 숨기지 않습니다.
- 단계 변경 시 새 단계 제목으로 포커스와 스크롤을 이동하되, 고정 헤더가
  제목을 가리지 않도록 `scroll-padding-top`과 `scroll-margin-top`을 사용합니다.
- 모달은 재시작 확인과 업데이트 내역처럼 중단이 필요한 경우에만 사용합니다.

## 자산과 접근성

- 기존 `bright-gym-tactics-board.webp`는 일반 개념 장식이며, 현재 해상도와 맥락이
  충분하므로 그대로 유지합니다. 빈 `alt`와 `aria-hidden`을 사용합니다.
- 새 이미지는 생성하지 않으며, 전술판·좌표·선수 표기는 정보성 SVG로 보존합니다.
- 화면 도구 설정은 저장하지 않습니다. 학생용 음성 안내·TTS·녹음은 범위에 넣지
  않으며, VoiceOver 검증도 이번 범위에서 제외합니다.
- 동적 피드백은 `role="status"`, 의미 있는 그룹 제목, 어린이도 이해할 수 있는
  문장을 사용합니다. 내부 좌표는 선택지에서 필요한 경우에만 보조 정보로 둡니다.

## 반응형 기준

| 폭 | 규칙 |
| --- | --- |
| 320~374px | 헤더 도구를 두 줄로 허용하고, 버튼은 세로로 쌓음 |
| 375~767px | 전술판을 먼저 보여 주고 선택지는 판 아래에 둠 |
| 768~1023px | 두 열을 유지하되 패널 최소 폭을 보장 |
| 1024px 이상 | 최대 폭 `1120px`, 판 열을 `1.2fr`, 패널 열을 `0.8fr`로 둠 |

## 금지 사항

- 외부 글꼴, 분석, 저장소, 네트워크 요청을 추가하지 않습니다.
- 어두운 모드, 점수·순위, 의미 없는 통계, 복잡한 전문 용어를 추가하지 않습니다.
- 같은 크기의 카드 반복, 장식용 그라디언트, 이모지 아이콘, 레이아웃을 움직이는
  hover, 좌표를 사실처럼 과장하는 새 그림을 사용하지 않습니다.
